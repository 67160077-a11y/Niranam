## 🛠️ ขั้นตอนการดำเนินงานและรายละเอียดทางเทคนิค

### ด่านที่ 1: การรักษาความปลอดภัยโครงสร้างพื้นฐานและการเข้าถึง (Secure Infrastructure & Access Control)
1. **การกำหนดความปลอดภัย SSH:**
   * ปิดการเข้าสู่ระบบด้วยสิทธิ์ `root` โดยตรง
   * ปิดการยืนยันตัวตนด้วยรหัสผ่าน (Password Authentication)
   * บังคับใช้การยืนยันตัวตนด้วย Public Key Infrastructure (PKI) ผ่านไฟล์คีย์ส่วนตัว (`.pem`) เท่านั้น
2. **การตั้งค่าโดเมนและใบรับรองความปลอดภัย:**
   * กำหนดค่า DuckDNS (`niranam.duckdns.org`) ชี้ไปยังหมายเลข IP ของ Azure VM
   * เปิดใช้งาน HTTPS ผ่าน Nginx Reverse Proxy เพื่อเข้ารหัสความปลอดภัยของการรับส่งข้อมูล

### ด่านที่ 2: การเสริมความปลอดภัยและการกรองทางภูมิศาสตร์ (Security Hardening & Geo-Fencing)
1. **การติดตั้ง Fail2ban:**
   * ตรวจสอบไฟล์ Log ของ Nginx และ SSH เพื่อตรวจจับการพยายามเข้าสู่ระบบที่ผิดปกติ และทำการบล็อก IP นั้นโดยอัตโนมัติ
2. **การกรอง IP ตามพื้นที่ประเทศไทย (Geo-Blocking):**
   * ใช้ชุดคำสั่ง `ipset` ร่วมกับ `iptables` เพื่อจำกัดการเข้าถึงพอร์ต `80` (HTTP) และ `443` (HTTPS) ให้ใช้งานได้เฉพาะผู้ใช้งานที่มีหมายเลข IP ภายในประเทศไทย (`th.zone`) เท่านั้น
   * **ตัวอย่างคำสั่งที่ใช้:**
     ```bash
     sudo ipset create thailand hash:net
     sudo iptables -I INPUT -p tcp -m multiport --dports 80,443 -m set ! --match-set thailand src -j DROP
     ```

### ด่านที่ 3: การเพิ่มประสิทธิภาพระบบ (Performance Optimization)
1. **การตั้งค่า Nginx Browser Caching:**
   * กำหนดค่า Cache ระยะยาวสำหรับไฟล์ประเภท Static (เช่น รูปภาพ, CSS, JavaScript) ด้วยคำสั่ง `expires max` และ `Cache-Control` เพื่อลดภาระการประมวลผลของเซิร์ฟเวอร์และทำให้หน้าเว็บไซต์โหลดเร็วขึ้น

### ด่านที่ 4: ระบบตรวจสอบและวิเคราะห์ล็อกสำหรับ AI (AI-Ready Monitoring & Dashboard)
1. **การวิเคราะห์ Log อัตโนมัติ:**
   * ติดตั้งและใช้งาน **GoAccess** เพื่อแปลงไฟล์ Log การเข้าใช้งานของ Nginx (`access.log`) ให้เป็นหน้าเว็บ Dashboard ในรูปแบบกราฟิกและตารางสรุปผล (`/var/www/html/dashboard.html`)
2. **การตั้งเวลาทำงานอัตโนมัติ (Cron Job):**
   * ตั้งค่าระบบ Cron ให้ทำการสแกนและอัปเดตข้อมูลหน้า Dashboard ทุกๆ 5 นาที เพื่อให้ได้ข้อมูลที่สดใหม่เสมอ:
     ```bash
     */5 * * * * goaccess /var/log/nginx/access.log -o /var/www/html/dashboard.html --log-format=COMBINED
     ```
   * ข้อมูลจาก Dashboard นี้สามารถนำไปส่งให้ AI (เช่น ChatGPT หรือ Gemini) วิเคราะห์พฤติกรรมการโจมตีหรือตรวจสอบช่องโหว่ได้อย่างมีประสิทธิภาพ
